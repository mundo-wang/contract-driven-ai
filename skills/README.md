# Agent Skill 使用指南

本目录包含契约驱动式 AI 开发所需的 16 个 Agent Skill。每个 Skill 均为独立、完整的 AI 行为规范文件，AI Agent 可在对应环节直接读取并执行。

---

## 什么是 Agent Skill

Agent Skill 是一份结构化的 AI 行为规范，定义了 AI 在特定任务场景下的：

- **任务目标**：本次任务需要达成的结果
- **执行前提**：开始任务前必须满足的条件和必须读取的资料
- **具体步骤**：任务执行的详细流程和阶段划分
- **执行约束**：任务执行过程中必须遵守的硬性规则
- **完成标准**：任务结束必须满足的检查项

每个 Skill 均独立成文，可在指定仓库后直接读取执行，也可将其完整内容复制粘贴至 AI 对话窗口中使用。

### L3 复杂需求的阶段拆分

对于 L3 级复杂需求，应将需求拆分为多个可独立交付的阶段。每个阶段均按上述 L2 流程独立执行：完成该阶段的产品契约、后端技术契约、后端测试契约、后端开发与测试、前端技术契约、前端测试契约、前端开发与测试，然后进入下一阶段。

## 独立会话建议

为减少上下文污染和自我验证偏差，建议在前后端技术契约与测试契约编写、前后端代码开发、测试及代码审查等关键阶段，分别创建独立的 AI 对话窗口。其中，需求分析与产品契约编写应在同一个对话窗口中完成，其余阶段各自使用独立窗口：

| 环节 | 建议 Skill |
|------|-----------|
| 项目上下文初始化 | Skill 1 |
| 需求分析与产品契约 | Skill 2 + Skill 4（同一窗口） |
| 后端技术契约编写 | Skill 5 |
| 后端测试契约编写 | Skill 6 |
| 后端三份契约独立审查 | Skill 7 |
| 后端代码开发 | Skill 8 |
| 后端接口自动化测试 | Skill 9 |
| 后端交付成果独立审查 | Skill 10 |
| 前端技术契约编写 | Skill 11 |
| 前端测试契约编写 | Skill 12 |
| 前端三份契约独立审查 | Skill 13 |
| 前端代码开发 | Skill 14 |
| 前端页面自动化测试 | Skill 15 |
| 前端交付成果独立审查 | Skill 16 |

**L1 轻量级交付**（Skill 3）可由同一 AI Agent 在同一窗口中完成全部工作，无需拆分多个会话。

## Skill 清单

### 项目与需求阶段

| Skill | 名称 | 说明 |
|-------|------|------|
| [Skill 1](skill-01-项目上下文初始化.md) | 项目上下文初始化 | 分析项目代码，初始化项目上下文文档，包含项目静态约定及动态信息索引 |

## 使用方式

### 方式一：仓库内直接读取（推荐）

在具备文件读取能力的 AI Agent 环境中，直接让 AI 读取对应 Skill 文件：

```
请读取 skills/skill-05-后端技术契约.md，然后按其中定义的流程执行后端技术契约编写任务。
```

### 方式二：复制粘贴

将 Skill 文件的完整内容复制粘贴至 AI 对话窗口中，根据实际需求补充必要信息后发送。

### 前置要求

每个 Skill 均定义了「执行前提」和「前置分析反问」环节。AI 在开始执行前，必须先完成资料分析和不确定点识别，向开发者提问确认后方可继续。开发者不应跳过这一环节。

---

## 契约文档规范

所有 Skill 均遵循统一的文档管理规范：

- **存放位置**：`交付契约/<需求名称>/<版本号>/`
- **版本命名**：新需求使用 v1，迭代使用 v2、v3 等
- **历史版本保留**：不得直接覆盖历史版本契约
- **完整生成**：新版本必须生成完整的契约内容，不能只记录本次变更

详细的契约目录结构、内容模板及裁剪规则，请参阅 [docs/02-契约文档体系.md](../docs/02-契约文档体系.md)。
